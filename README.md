# Projetos em PHP

Repositório destinado às atividades da disciplina de Prática de PHP.

## 📌 Projetos

### 🩷 Calculadora PHP

Calculadora desenvolvida em PHP com as quatro operações matemáticas básicas:

- Adição
- Subtração
- Multiplicação
- Divisão

O projeto utiliza PHP, HTML e CSS, com uma interface simples.

### 🌸 Cadastro de Aluno

Sistema simples desenvolvido em PHP para cadastrar alunos e armazenar os dados em um arquivo `.txt`. O projeto utiliza:

- PHP
- HTML
- CSS
- Arquivo TXT

Os dados cadastrados são armazenados no arquivo `alunos.txt`.

### 💗 Excluir Disciplina

Sistema em PHP para exclusão de disciplinas cadastradas em um arquivo `.txt`. O usuário informa a sigla da disciplina, o sistema localiza o registro correspondente e remove a linha do arquivo. O projeto utiliza:

- PHP
- HTML
- CSS
- Arquivo TXT

Os dados das disciplinas são armazenados no arquivo `disciplinas.txt`.

### 💖 Listar Alunos (CRUD completo)

Sistema em PHP para gerenciamento de alunos, com listagem em tabela e ações de cadastro, alteração e exclusão. Os dados são armazenados em um arquivo `.txt`. O projeto é composto por:

- Listagem dos alunos cadastrados, com botões de **Alterar** e **Excluir** para cada registro
- Cadastro de novo aluno
- Tela de alteração, que carrega os dados do aluno selecionado em um formulário
- Tela de confirmação de exclusão, exibindo os dados antes de remover o registro

O projeto utiliza:

- PHP
- HTML
- CSS
- Arquivo TXT

Os dados cadastrados são armazenados no arquivo `alunos.txt`.
